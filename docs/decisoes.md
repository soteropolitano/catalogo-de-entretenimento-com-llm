# Decisões do MVP

## Usar o Google Sheets como base

O catálogo precisava ser legível, corrigível e fácil de filtrar. Uma aplicação e um banco próprios não eram necessários para validar a organização e a qualidade das recomendações.

## Separar estado de confiança

O estado descreve o relacionamento com a obra. A confiança descreve o quanto a identificação ou a atualização é segura. Misturar os dois faria um título duvidoso parecer confirmado.

## Manter aliases

Filmes, séries e jogos podem aparecer com título original, tradução ou abreviação. Os aliases evitam duplicidade sem apagar a forma usada na conversa.

## Criar visões sem duplicar a base

`Quero ver`, `Assistidos`, `Em andamento` e `Revisão` funcionam como visões da base principal. A fonte de verdade continua sendo o catálogo.

## Preservar a avaliação pessoal

Notas externas são apoio. A avaliação registrada pelo usuário é o sinal mais direto para calibrar futuras recomendações.

## Manter os dados reais privados

Histórico de consumo e preferências formam um perfil pessoal. O repositório público mostra o método com registros fictícios e mantém a base oficial no Drive.
