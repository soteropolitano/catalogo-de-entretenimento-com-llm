# Regras de manutenção e recomendação

- A aba **Catálogo** é a base editável; as demais listas são visualizações.
- Use somente os estados definidos na planilha.
- Registros incertos ficam em **Revisão** até serem confirmados.
- Atualize um registro existente quando o título já estiver no catálogo; crie outro ID apenas para uma obra diferente.
- Preserve aliases e a classificação original para reduzir duplicidades.
- Consulte o histórico antes de recomendar e não trate um título citado como concluído.
- Diferencie informação confirmada de estimativa.
- Verifique fontes atuais antes de afirmar disponibilidade, lançamento ou plataforma.
- Use avaliações externas como apoio; o histórico e as avaliações registradas na base orientam a recomendação.
- Considere a energia mental necessária para escolher algo compatível com o momento.
