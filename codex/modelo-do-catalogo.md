# Modelo do catálogo

A aba editável **Catálogo** usa os campos abaixo:

| Campo | Uso |
|---|---|
| id | Identificador estável do registro |
| titulo | Título principal |
| aliases | Títulos alternativos e nomes em outros idiomas |
| categoria | Tipo de conteúdo |
| status_consumo | Estado atual do consumo |
| progresso | Temporada, episódio ou etapa |
| nota / nota_num | Avaliação em texto e valor numérico |
| prioridade | Ordem de interesse |
| proxima_acao | Próxima validação ou etapa |
| confirmacao_status | Indica se o registro foi confirmado |
| origem / confianca | De onde veio o dado e grau de confiança |
| observacao | Contexto adicional |
| fonte_avaliacao_prioritaria | Fonte externa consultada |
| url_fonte_prioritaria | Link da fonte principal |
| fontes_secundarias | Fontes complementares |
| ultima_atualizacao | Data da atualização |
| regra_recomendacao | Regra aplicável ao item |
| subtipo_original | Classificação original preservada |
| ordem_prioridade | Ordem numérica legada |

A planilha mantém visualizações automáticas para itens pendentes, concluídos, em andamento e em revisão. As visualizações não devem ser editadas diretamente.
