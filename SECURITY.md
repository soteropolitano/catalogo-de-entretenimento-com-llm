# Segurança e privacidade

O histórico real de entretenimento é privado. Ele pode revelar preferências, rotina e informações pessoais que não são necessárias para explicar a arquitetura do projeto.

## Não publicar

- exportações da planilha oficial;
- histórico e avaliações pessoais;
- links privados do Google Drive e Google Sheets;
- transcrições de conversas;
- credenciais, chaves ou tokens;
- snapshots e backups reais.

Os exemplos deste repositório usam títulos e serviços fictícios. Uma exportação destinada ao GitHub deve ser revisada antes da publicação, mesmo quando parece conter apenas dados de entretenimento.

Se um arquivo real for publicado por engano, não abra uma issue reproduzindo o conteúdo. Avise o responsável de forma privada para que o histórico do repositório seja corrigido.
